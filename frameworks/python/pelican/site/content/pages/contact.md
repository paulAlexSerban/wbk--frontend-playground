## About This Project

This Pelican site is part of a larger **Frontend Playground** workbook that explores various static site generators and frontend frameworks. If you're interested in:

- Static site generation with Python
- Jinja2 templating techniques
- Modern web development workflows
- Pelican customization and plugins

Feel free to explore the codebase and reach out with questions!
