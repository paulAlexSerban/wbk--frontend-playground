# Like

Double-click an image to create animated floating heart icons with a counter.

**Source:** [50 Projects In 50 Days - HTML, CSS & JavaScript](https://www.udemy.com/course/50-projects-50-days/)

## Concepts

- `double-click-detection` — tracking click timestamps to detect clicks within 800ms of each other
- `dynamic-font-awesome-icons` — creating and positioning Font Awesome icons via JS
- `animation-sequences` — `@keyframes grow` scales and fades hearts outward
- `event-coordinate-tracking` — calculating click position relative to target element
- `incremental-counter` — updating a display counter on each like

## Commands

```bash
# Development
yarn --cwd projects/components/like dev

# Production build
yarn --cwd projects/components/like build
```
