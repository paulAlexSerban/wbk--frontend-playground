# Form Components

Collection of form-focused UI patterns and controls.

Source: `libraries/dev-days-matrix-library/src/library/components/form-components`

## Architecture

- `src/styles/_*.scss` split modules with local `_abstracts.scss`
- `src/scripts/_*.js` split modules with `index.js` entry
- `src/_partials/_*.hbs` variation partials composed in `body.hbs`

## Commands

```bash
yarn --cwd projects/components/form-components dev
yarn --cwd projects/components/form-components build
```
