# Timer

Timer component variants with countdown and elapsed-time behavior.

Source: `libraries/dev-days-matrix-library/src/library/components/timer`

## Architecture

- `src/styles/_*.scss` split modules with local `_abstracts.scss`
- `src/scripts/_*.js` split modules with `index.js` entry
- `src/_partials/_*.hbs` variation partials composed in `body.hbs`

## Commands

```bash
yarn --cwd projects/components/timer dev
yarn --cwd projects/components/timer build
```
