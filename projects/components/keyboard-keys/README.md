# Keyboard Keys

Displays the key name, keyCode, and code values when any keyboard key is pressed.

**Source:** [50 Projects In 50 Days - HTML, CSS & JavaScript](https://www.udemy.com/course/50-projects-50-days/)

## Concepts

- `keyboard-events` — listening to `keydown` on `window`
- `event.key` / `event.keyCode` / `event.code` — different representations of a key press
- `dom-manipulation` — dynamically replacing innerHTML on each keystroke

## Commands

```bash
# Development
yarn --cwd projects/components/keyboard-keys dev

# Production build
yarn --cwd projects/components/keyboard-keys build
```
