# Image

Image component patterns and responsive image demos.

Source: `libraries/dev-days-matrix-library/src/library/components/image`

## Architecture

- `src/styles/_*.scss` split modules with local `_abstracts.scss`
- `src/scripts/_*.js` split modules with `index.js` entry
- `src/_partials/_*.hbs` variation partials composed in `body.hbs`

## Commands

```bash
yarn --cwd projects/components/image dev
yarn --cwd projects/components/image build
```
