# Big Frontend Dev

Base page template for BigFrontend.dev challenge implementations.

Source: `libraries/dev-days-matrix-library/src/system/templates/big-frontend-dev`

## Concepts

- `page-template` - reusable HTML shell for challenge pages
- `shared-grid-layout` - integrates common 12-column flexbox grid styles
- `system-foundation` - minimal system-level starting point with no runtime JS

## Commands

```bash
yarn --cwd projects/systems/big-frontend-dev dev
yarn --cwd projects/systems/big-frontend-dev build
```
