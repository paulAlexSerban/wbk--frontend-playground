# Frontend Mentor

Base page template for Frontend Mentor challenge implementations.

Source: `libraries/dev-days-matrix-library/src/system/templates/frontend-mentor`

## Concepts

- `page-template` - reusable HTML shell for challenge pages
- `shared-grid-layout` - integrates a localized 12-column flexbox grid stylesheet under `src/styles/`
- `attribution-footer` - challenge attribution text included in the page body

## Commands

```bash
yarn --cwd projects/systems/frontend-mentor dev
yarn --cwd projects/systems/frontend-mentor build
```
