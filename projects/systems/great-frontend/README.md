# Great Frontend

Base page template for Great Frontend exercises.

Source: `libraries/dev-days-matrix-library/src/system/templates/great-frontend`

## Concepts

- `page-template` - reusable HTML shell for Great Frontend exercise pages
- `shared-grid-layout` - integrates a localized 12-column flexbox grid stylesheet under `src/styles/`
- `portable-style-dependencies` - avoids helper-driven cross-project style imports

## Commands

```bash
yarn --cwd projects/systems/great-frontend dev
yarn --cwd projects/systems/great-frontend build
```
