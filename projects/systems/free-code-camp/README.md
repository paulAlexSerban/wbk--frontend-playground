# Free Code Camp

Base page template for freeCodeCamp challenge implementations.

Source: `libraries/dev-days-matrix-library/src/system/templates/free-code-camp`

## Concepts

- `page-template` - reusable HTML shell for challenge pages
- `shared-grid-layout` - integrates a localized 12-column flexbox grid stylesheet under `src/styles/`
- `system-foundation` - minimal system-level starting point with no runtime JS

## Commands

```bash
yarn --cwd projects/systems/free-code-camp dev
yarn --cwd projects/systems/free-code-camp build
```
