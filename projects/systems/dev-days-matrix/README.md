# Dev Days Matrix

Base page template for Dev Days Matrix projects.

Source: `libraries/dev-days-matrix-library/src/system/templates/dev-days-matrix`

## Concepts

- `page-template` - reusable HTML shell for challenge pages
- `attribution-footer` - fixed attribution footer rendered in the body
- `background-css-variables` - optional background image/gif variables injected through template data

## Commands

```bash
yarn --cwd projects/systems/dev-days-matrix dev
yarn --cwd projects/systems/dev-days-matrix build
```
