# Codepen Challenges

Base page template for CodePen challenge implementations.

Source: `libraries/dev-days-matrix-library/src/system/templates/codepen-challenges`

## Concepts

- `page-template` - reusable HTML shell for challenge pages
- `shared-grid-layout` - integrates a localized 12-column flexbox grid stylesheet under `src/styles/`
- `system-foundation` - minimal system-level starting point with no runtime JS

## Commands

```bash
yarn --cwd projects/systems/codepen-challenges dev
yarn --cwd projects/systems/codepen-challenges build
```
