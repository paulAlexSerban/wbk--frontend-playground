# Frontend Practice

Base page template for Frontend Practice challenge implementations.

Source: `libraries/dev-days-matrix-library/src/system/templates/frontend-practice`

## Concepts

- `page-template` - reusable HTML shell for challenge pages
- `shared-grid-layout` - integrates a localized 12-column flexbox grid stylesheet under `src/styles/`
- `portable-style-dependencies` - avoids helper-driven cross-project style imports

## Commands

```bash
yarn --cwd projects/systems/frontend-practice dev
yarn --cwd projects/systems/frontend-practice build
```
