# Landing

Landing page template baseline containing hero, feature, testimonial, and footer sections.

Source: `libraries/dev-days-matrix-library/src/system/templates/landing`

## Concepts

- `page-template` - reusable shell for marketing-style pages
- `hero-section` - top-level call-to-action content hierarchy
- `feature-list` - structured benefit list section
- `system-foundation` - minimal template baseline for future compositions

## Commands

```bash
yarn --cwd projects/systems/landing dev
yarn --cwd projects/systems/landing build
```
