# Card

Card pattern collection including placeholder and QR card demos.

## Improvements and expansions to consider:

- add responsive density/card-size variants
- define content-slot conventions for richer compositions
- verify hover/focus parity for interactive cards
- add keyboard navigation between active cards
- add reduced-motion fallback for transition-heavy variants
- add ARIA roles/states for interactive cards (e.g. role="button" + aria-pressed for toggle cards)
- add loading/error state variants with skeletons/placeholders
- add focus-visible styles for keyboard users
- add support for image/media slots with aspect ratio handling
- add notes on card performance considerations (e.g. lazy-loading, virtualization for large lists)
- add examples of card usage in different contexts (e.g. product cards, profile cards, article cards)
