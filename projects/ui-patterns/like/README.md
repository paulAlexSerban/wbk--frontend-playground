# Like

Like interaction pattern with animated feedback and state toggles.

Source: `libraries/dev-days-matrix-library/src/library/patterns/like`

## Architecture

- `src/styles/_*.scss` split modules with local `_abstracts.scss`
- `src/scripts/_*.js` split modules with `index.js` entry
- `src/_partials/_*.hbs` variation partials composed in `body.hbs`

## Commands

```bash
yarn --cwd projects/components/like dev
yarn --cwd projects/components/like build
```
