# Drag N Drop

Interactive drag-and-drop component demo with one draggable tile and multiple drop targets.

## Concepts

- HTML5 drag and drop events
- DOM event handling
- dynamic class state updates

## Improvements and expansions to consider:

- add support for multiple draggable items and corresponding drop targets
- implement visual feedback for valid/invalid drop targets during dragging
- add keyboard accessibility for drag-and-drop interactions
- explore accessibility features like ARIA attributes and focus management
- add unit tests for drag-and-drop behavior and accessibility
- make the component responsive for different screen sizes
- allow customization of draggable item and drop target styles through props or CSS variables
- optimize drag-and-drop performance and compatibility across browsers
- consider adding a "snap to grid" feature for more precise drop placement
- add support for touch devices with touch events for dragging and dropping
- implement a reset button to return draggable items to their original positions
- explore different visual styles for draggable items and drop targets, such as color changes or animations on drag start and drop
- add keyboard-accessible drag alternatives for accessibility parity
- support touch interactions for mobile devices
- add visual placeholder state while dragging over empty slots
