# List

List component variants for definition and unordered content.

Source: `libraries/dev-days-matrix-library/src/library/components/list`

## Architecture

- `src/styles/_*.scss` split modules with local `_abstracts.scss`
- `src/scripts/_*.js` split modules with `index.js` entry
- `src/_partials/_*.hbs` variation partials composed in `body.hbs`

## Commands

```bash
yarn --cwd projects/components/list dev
yarn --cwd projects/components/list build
```
