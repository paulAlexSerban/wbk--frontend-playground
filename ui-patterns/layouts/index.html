Variation 3

Stack Primitive - Successive

Stack adds vertical rhythm only where elements meet.

Stack is a primitive layout component that can be used to create consistent vertical spacing between elements in a layout. It can be used in both successive and recursive modes, depending on the desired spacing behavior.

In successive mode:

Stack applies spacing only between direct siblings, meaning that only elements that are directly adjacent to each other will have spacing applied.

This is useful for creating a clean and organized layout where elements are clearly separated.

In recursive mode:

Stack applies spacing between all nested elements, regardless of their hierarchy.

This means that even elements that are not direct siblings will have spacing applied between them.
